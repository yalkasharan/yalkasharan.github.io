Azure · Azure ML · Docker · FastAPI · Streamlit · CI/CD

End-to-End ML Pipeline on Microsoft Azure

Problem

Building a production-grade ML system requires far more than a trained model — it needs reliable data ingestion, reproducible preprocessing, automated retraining, containerised serving, and a usable interface. Most academic projects stop at the notebook; this one goes all the way to deployment.

Approach

Designed a modular pipeline on Azure: raw data lands in Azure Blob Storage, flows through a preprocessing layer, and feeds Azure ML for model training. The trained model is packaged in a Docker container, served via FastAPI, and made accessible through a Streamlit UI. A CI/CD pipeline handles automated testing and deployment.

✔ Full CI/CD integration ✔ Production-grade serving ✔ Containerised & scalable
